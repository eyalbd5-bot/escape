# Escape · מנוע גילוי נסיעות

אפליקציית ווב אישית לגילוי ותכנון נסיעות. Vite + React + TypeScript, RTL מלא, עברית, mobile-first (max-width ~480px).

נבנית שלב-שלב לפי `escape-spec.md` (סעיף 13 — שלבי בנייה).

## ארכיטקטורה (חשוב — ראו `HANDOFF.md`)

הנכס העמיד הוא **שכבת הנתונים**, לא ה-UI. כל מה שה-UI צריך מגיע מפונקציה אחת:

```ts
import { getDestinationData } from './src/aggregator'
const response = await getDestinationData({ city, startDate, endDate, nights })
```

- `src/core/` — החוזה (`types.ts`), ה-runner (`contract.ts`), שכבת HTTP (`http.ts`), קונפיג (`config.ts`).
- `src/sources/` — מקור לכל קובץ, כולם ממשים `Source<T>` (currency/weather/info/media/sports/flights/hotels/events/restaurants/itinerary).
- `src/aggregator.ts` — **נקודת הכניסה היחידה**: fan-out מקבילי, partial-tolerant.
- `src/components/` — **Reference UI בלבד** (ניתן להחלפה/רגנרציה), קורא רק מה-response, בלי fetch/לוגיקה.

מיועד ל-handoff לפלטפורמת בנייה ויזואלית (Lovable/Bolt/v0): בונים UI חדש מעל אותה פונקציה. פירוט מלא ב-`HANDOFF.md`.

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח על http://localhost:5173
npm run build    # בדיקת טיפוסים + build לפרודקשן (dist/)
npm run preview  # תצוגה מקדימה של ה-build
npm run test     # סוויטת Vitest (מקורות + aggregator, כולל source-down)
```

> הערה: Node הותקן מקומית תחת `~/.local/node` ונוסף ל-`PATH` ב-`~/.zshrc`.
> אם `node`/`npm` לא נמצאים, פתחו טרמינל חדש או הריצו:
> `export PATH="$HOME/.local/node/bin:$PATH"`

## מצב נוכחי — שלבים 1–2 ✅

**שלב 1 — שלד**
- שלד Vite + React + TS, RTL, mobile-first, פריסה מוכנה ל-build.
- **מסך נחיתה** — כותרת, בורר יעד, שדות תאריך (הלוך/חזור), כפתור "צור את המסע" + ולידציה.
- **בורר יעד** — גלגלת שנפתחת ב-focus/קליק עם כל היעדים; סינון בהקלדה (עברית / אנגלית / IATA).
- **דף בית** — hero נמוך, ספירה לאחור לטיסה, רשת כרטיסים 2 עמודות שנפרסת על המסך (מינ' גלילה).
- **בר עליון** קבוע — חזרה (חץ RTL), שם יעד+דגל+תאריכים (→ דף בית), המבורגר.
- **תפריט המבורגר** + **מחסנית ניווט** (back). חזרה מדף הבית → חזרה לבורר. back פעיל בכל מסך.

**שלב 2 — מקורות ללא מפתח (חי)**
- **מטבע** — ממיר ₪ ↔ מטבע היעד חי (Frankfurter / ECB), **דו-כיווני** (כפתור הפיכה ⇄). שדה → תוצאה + שער.
  המקור הוא `api.frankfurter.dev` (ה-host העדכני; `api.frankfurter.app` הישן כבר לא מגיב).
- **מזג אוויר** — תחזית 5 ימים חיה (Open-Meteo: geocoding → forecast); תקציר בכרטיס "מידע" בדף הבית.
- **תיאור יעד** — תקציר עברי חי מ-Wikipedia (he) שמחליף את שעון-העצר בדף הבית.
- **תמונת יעד** — מ-Wikipedia REST (en) → hero + רקע דינמי עם crossfade.
- **מידע נוסף** — מזג אוויר חי + "חיוני לדעת" אצור (ויזה 🇮🇱 / תקע / **אזור-זמן ב-GMT + הפרש מתל אביב** / טיפים).
- כל קריאת רשת עטופה ב-try/catch עם fallback ברור — כשל מקור לא שובר מסך.

**שיפורים (ללא מפתח)**
- **תמונות מתחלפות** — hero עם 3–6 תמונות אמיתיות ומגרות של היעד מ-Wikimedia Commons
  (חיפוש "{city} skyline" + סינון לפי שם העיר), עם crossfade ו-Ken Burns. הרקע הוא התמונה הטובה ביותר.
- **מונדיאל 2026** — משחקי מונדיאל אמיתיים בעיר מארחת (TheSportsDB ליגה 4429, שאילתה לפי יום בטווח הנסיעה,
  סינון לפי אצטדיון מארח). מיאמי ב-15.6/24.6 → משחקים ב-Hard Rock Stadium. מכסה את 16 ערי המונדיאל.
- **מסעדות** — מסך ייעודי עם סינון לפי סוג חוויה: כוכבי מישלן (מדריך MICHELIN), יוקרה/fine-dining,
  ארוחה קלה, אוכל מקומי, צמחוני/טבעוני, בתי קפה, נוף/גג — כל קטגוריה פותחת תוצאות אמיתיות.
- דף הבית: 8 כרטיסים (נוספו מסעדות + חירום).

**שלב 5 — אירועים אמיתיים (ללא מפתח) + הפרדת מקורות**
- **ספורט אמיתי**: משחקים קרובים אמיתיים מ-TheSportsDB (מפתח ציבורי חינמי, ללא הרשמה, CORS תקין)
  לפי מיפוי קבוצה→עיר אצור ל-24 הערים (`src/data/sportsTeams.ts`). מסוננים לטווח התאריכים של הנסיעה;
  אם אין בטווח — מוצגים המשחקים הקרובים. ערים ללא מיפוי → קישורי חיפוש.
- **אזור רשמי**: כרטיסי ספורט מובנים (TheSportsDB) + Ticketmaster (כרטיסים רשמיים).
- **אזור לא רשמי** (עם תווית אזהרה קבועה): Songkick / Eventim / Bandsintown / חיפוש Google — קישורים מסוננים לפי עיר.
- **מחירים**: אין מקור מחירים חי ללא מפתח, לכן הטווחים הם **הערכה** (טיסות לפי מרחק, מלונות לפי לילה),
  והכפתורים פותחים מחירים אמיתיים בזמן אמת (Skyscanner / Google Flights / Booking). מסומן בבירור למשתמש.

**שלב 4 — דאטה-סטים**
- **בורר יעד מלא** — ~3,100 ערים מ-OpenFlights (רק שדות-תעופה עם טיסות סדירות, מאוחד לפי עיר),
  כל אחת עם IATA, מדינה (ISO2), מטבע, ו-lat/lng. ה-24 האצורות מופיעות ראשונות (focus), והקלדה מסננת את כל הדאטה-סט (תקרה 50 תוצאות).
- נבנה ע"י `scripts/gen_cities.py` → `src/data/citiesFull.json` (מיזוג מ-airports/routes/restcountries).
- **טיפול חינני בערים לא-אצורות**: דגל מחושב מ-ISO2, שם אנגלי, הערכת מחיר טיסה לפי מרחק אווירי מ-TLV,
  מחיר לילה ברירת-מחדל, ותיאור/אתרים/אולם שמושמטים בעדינות (fallback). מטבע ומזג-אוויר עובדים תמיד.
- **מידע מדינות מורחב** — ~52 מדינות (ויזה 🇮🇱 / תקע / אזור-זמן / טיפים / חירום / Airalo); השאר נופלים ל-fallback.

**שלב 3 — Deep links (קישור החוצה, ללא מפתח)**
- **טיסות** — טווח מחיר + Skyscanner + Google Flights (מוצא TLV, יעד, תאריכים).
- **מלונות** — טווח מחיר ל-N לילות + Booking (עיר + תאריכים + 2 בוגרים).
- **אירועים** — שני אזורים: רשמי (Ticketmaster) ולא-רשמי (חיפוש רשת / Eventim) עם תווית אזהרה.
- **מסלול** — שלד יומי + מקומות מרכזיים אצורים לעיר (תצוגה מקדימה גם בכרטיס בדף הבית).
- **מידע** — קישורי מסעדות/תחבורה (Google Maps) ו-eSIM (Airalo).
- **חירום** — מספר חירום מקומי, שגרירות ישראל (Maps), אזהרת מסע (מל"ל), ביטוח (placeholder).
- כרטיסי דף הבית מציגים תצוגה מקדימה לפני הלחיצה: מסלול → 3 אתרים, אירועים → אולם מרכזי.

## אופציונלי בעתיד (דורש מפתחות)

שדרוג מ-deep-links לנתונים מובנים מלאים: Ticketmaster Discovery (כל האירועים, לא רק ספורט),
football-data.org (כל הליגות), ומחירי טיסה/מלון אמיתיים (Travelpayouts / Amadeus).
המפתחות נכנסים ל-`.env` (ראו `.env.example`) — לא נדרש לשימוש הנוכחי.

**שלב 6 — מסלול (תכנון AI ללא מפתח)**
- כרטיס "✨ תכנון מסלול חכם" במסך המסלול: כפתורי Perplexity / ChatGPT / Claude שנפתחים עם

- בנוסף: מקומות מרכזיים אצורים + שלד יומי ראשוני.
